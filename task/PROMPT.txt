为报表模板实现一个受限表达式解释器，模板不可信，允许的数据只有调用方传入的 JSON。

请从空目录实现以下可运行工具。环境为 Windows、Python 3.12、仅CPU；不使用Docker或真实外部服务。除题面明确允许的cryptography外只用标准库。输入样例、模拟组件和测试数据由你在项目内构造，不存在另行提供的附件。

核心要求：
1. 语法只允许字面量、索引、算术、比较、短路逻辑、条件表达式和白名单纯函数；自己解析语法树，不得调用 eval、exec 或通过反射执行宿主表达式。任何属性访问、动态调用和未声明语法都拒绝。允许直接使用标准库ast解析后逐节点白名单解释，不要求重写词法器；语法不合法即使位于死分支也拒绝，合法死分支中的运行期错误则不触发。
2. 每次求值共享步数、递归深度、结果字节数三种预算；列表和字符串构造在分配前计费，短路分支不执行也不计执行步数，嵌套函数不能重置预算。整数位数和指数运算必须有明确上界。
3. 编译缓存必须绑定语法版本与能力集；并发调用不能共享可变预算或污染输入。输出错误类型、源码区间、已消耗预算，错误信息不得回显输入中的敏感字段值。

必须覆盖的验收场景：正常嵌套模板、死分支非法操作、巨大整数、拼接膨胀、缓存换能力集及两个并发租户；用进程内存/时间约束验证拒绝发生在大对象生成前。

交付源代码、README、样例及自动化测试。提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v 两个入口；cases.json可引用项目内源文件或二进制样例。输入输出schema、错误码及未写明的非安全性细节自行设计并完整说明，不能放宽上述要求。测试必须断言具体结果、状态或证据，不能只打印成功；固定种子可重放。所有操作局限在项目测试目录和本机模拟服务。
